5 DAKİKADA KURULUM (kendi bilgisayarınızda)
-------------------------------------------
  1. Bu klasörü örneğin C:\CvPortal konumuna çıkarın.

  2. uygulama\appsettings.json dosyasını Not Defteri ile açın.
     Bilgisayarınızda SQL Server Express kuruluysa hiçbir şeyi
     değiştirmenize gerek yoktur. Farklı bir SQL Server kullanıyorsanız
     "DefaultConnection" satırını düzenleyin.

  3. uygulama\CvPortal.Web.exe dosyasına çift tıklayın.
     Veritabanı ve tablolar otomatik oluşturulur.

  4. Tarayıcıda şu adresi açın:   http://localhost:5000/setup
     Adınızı ve yönetici hesabınızı girip kurulumu tamamlayın.

  5. Yönetim paneli:              http://localhost:5000/Admin


SUNUCUYA KURULUM (IIS)
----------------------
  KURULUM.md dosyasının 4. bölümüne bakın.


ŞİFREMİ UNUTTUM
---------------
  uygulama klasöründe bir komut istemi açıp:
    CvPortal.Web.exe reset-password <kullanıcı-adı> <yeni-şifre>


YEDEKLEME
---------

  2. Yüklenen dosyalar: uygulama\App_Data\uploads klasörünü kopyalayın.
